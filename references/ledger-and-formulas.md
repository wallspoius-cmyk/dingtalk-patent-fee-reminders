# 台账适配与公式

## 只读核对

示例命令（实际路径按环境替换）：

```text
python -X utf8 scripts/audit_patent_ledger.py input.xlsx --out work/ledger-audit.json
```

可选 `--sheet`、`--header-row`。脚本查找常见字段标题，只提取专利台账相关字段，输出原值、源单元格、类型、格式、显示申请号和疑点；不会保存或修改源工作簿。输出 JSON 放在当前工作目录，包含用户数据，不能复制进技能目录。

脚本结果是结构审计，不证明法律期限或缴费状态。日期字符串只接受明确的年月日格式；其他日期保留原值并提示核对。混用多个缴费日期标题或同一标题重复出现时，查看映射警告并人工确定基准列。

## 建议字段

| 字段 | 用途 |
| --- | --- |
| 专利名称、申请号 | 保留源值，申请号作为文本 |
| 缴费日、金额、年费名称 | 用户确认的下一次缴费安排 |
| 缴费状态 | 未缴费／已缴费／待核对，按需增加不启用 |
| 距离下一次缴费剩余日期 | 用户指定的列名可以保留，内容为整数天数 |
| 接收邮箱 | 用户指定收件邮箱 |
| 提前天数 | 用户选择的参数，不能固定为过去的7天或30天 |
| 提醒日期 | 云端自动计算，用于流程触发 |
| 原表分类、原表备注、源表行号 | 回查原始数据 |

不要求所有台账都采用完整字段集，只添加完成用户任务所需字段。不要将凭据作为台账字段。

## 钉钉 AI 表格已验证的公式

以下语法在2026年9月至10月的界面中验证过。先从当前编辑器插入字段或检查语法，保存后核对计算值；产品语法可能变化。

精确提前30天，并保留空日期：

```text
IF(ISBLANK([缴费日]),"",DATEADD([缴费日],-30,"days"))
```

若用户希望维护可变提前天数：

```text
IF(ISBLANK([缴费日]),"",DATEADD([缴费日],-[提前天数],"days"))
```

剩余天数：

```text
IF(ISBLANK([缴费日]),"",DAYS([缴费日],TODAY()))
```

提醒日期的显示格式设置为日期，并检查能否用作时间触发字段。剩余天数使用数字显示，不格式化为日期。校验 TODAY() 与用户所在日期一致；触发时区使用用户确认的时区。

独立算例：当日2026-10-01，缴费日2026-11-30，剩余60天；提前30天的提醒日期为2026-10-31。此算例用于核对函数方向和日历偏移，不是通用当前日期。

Excel 适配副本可使用 `IF(C2="","",C2-G2)` 计算提醒日期、`IF(C2="","",C2-TODAY())` 计算剩余天数，实际列位置依文件而定。导入后检查：Excel 公式通常成为缓存值，不能据此声称云端会自动重算，应另建或转换云端公式字段。

## 易错点

- 合并行仍可能是有效记录；不要仅按序号列非空计数。全空行不算记录。
- 数值申请号显示为 `0.0` 时，整数原值可能实际显示以 `.0` 结尾。按格式生成显示文本并保留原值，不能丢掉校验位。
- 缺少小数点的号码保留并标注，不能凭形状自行补点后当作正确号码。
- “已授权”描述专利状态，与本期费用支付状态不同。
- 发明与实用新型可能同名，不能按名称去重。
- 原缴费日比申请日周年晚一个月，可能是计划日或补缴安排；通过用户确认解决提醒口径，不自动推算法定截止日。
